## 📖 Tentang Repository

Repository ini berisi solusi pribadi untuk tantangan algoritma dan struktur data di LeetCode. Fokus utamanya adalah menulis kode Go yang bersih, efisien, dan mudah dibaca, sekaligus mendokumentasikan perjalanan belajar dalam memecahkan masalah komputasional.

Sebagian besar solusi ditulis sebagai file mandiri (`package main`) yang dapat dijalankan langsung untuk pengujian lokal, sementara solusi kontes diorganisir dalam subfolder terpisah.
